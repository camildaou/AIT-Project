**E05** (2026-11-02, 4-class single-label, MDL formulations) - `results/metrics/mdl_two_part_ladder_results.csv` - done

- Configuration: MDL trigram + two-part model cost L(M_e) (n-gram table code length)
- Question: Does adding the model description length L(M_e) per text help?
- Conclusion: No: L(M_e) (thousands of bits) swamps L(x|M_e) (~150 bits); every text is predicted as the smallest class (fear). Misapplication of two-part MDL, kept as a negative result.

**E06** (2026-11-05, 4-class single-label, MDL formulations) - `results/metrics/mdl_prior_ladder_results.csv` - done

- Configuration: MDL trigram + class prior -log2(N_e/N)
- Question: Does a training-frequency class prior help?
- Conclusion: Accuracy up at small/medium sizes, macro-F1 down in 38/40 runs: the prior suppresses fear.

**E19** (2026-11-05, 27-class single-label, add-k sweep) - `results/metrics/sl27_mdl_n2_k0p001_ladder_results.csv` - done

- Configuration: MDL27 bigram, add-k k=0.001
- Question: Is add-1 over-smoothing with V = 18.7k?
- Conclusion: Worst; prediction counts match true counts (admiration 346 vs 348) but accuracy drops to 0.30. A single global k cannot fix the bias without over-penalising unseen bigrams -> motivates Kneser-Ney.

**E20** (2026-11-05, 27-class single-label, Kneser-Ney) - `results/metrics/sl27_mdl_n2_knclass_ladder_results.csv` - done

- Configuration: MDL27 bigram, interpolated Kneser-Ney, per-class lower-order distribution, estimated discounts
- Question: Does back-off to a continuation unigram beat add-k?
- Conclusion: Selected: best validation macro-F1 at every size (0.324 vs 0.285 for add-1 at full size); test macro-F1 0.304 vs 0.279. Predictions now track true class frequencies (admiration 337 vs 348 true) and mid/rare classes improve (fear F1 0.17 -> 0.37, F1=0 classes 5 -> 2), but frequent distinctive classes drop (amusement 0.66 -> 0.48), so accuracy/kappa are lower than add-1 above ~4k examples (full size: acc 0.392 vs 0.428, kappa 0.354 vs 0.379).

**E21** (2026-11-05, 27-class single-label, Kneser-Ney) - `results/metrics/sl27_mdl_n2_knshared_ladder_results.csv` - done

- Configuration: MDL27 bigram, interpolated Kneser-Ney, lower-order distribution pooled over the training subset, estimated discounts
- Question: Does a shared back-off distribution help rare classes?
- Conclusion: Worse than per-class back-off at every size and below add-1 on validation (0.226 overall); pooling the lower order across classes makes the class models less distinctive. Hypothesis that sharing helps rare classes not supported.
